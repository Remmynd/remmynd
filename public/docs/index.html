The link

A reminder is a small piece of JSON, base64url-encoded, in one of two forms:

https://remmynd.space/r/eyJ0IjoiRGVtbyBkYXkiLCJzIjoiaHRxc3UifQ   shared (the default)
https://remmynd.space/#eyJ0IjoiRGVtbyBkYXkiLCJzIjoiaHRxc3UifQ    private, and every 1.x link
FormReaches the server?Used for
Shared /r/…Yes, in passing: the Worker reads it to fill the preview tags, then forgets it. Never stored, logged or cached.Links meant to be shared in chat
Private /#…No. Browsers never send what follows #.The Private link switch, and every 1.x link
KeyMeaningNotes
tTitleRequired
sStartMinutes since 1970 UTC, base 36
dLength in minutesLeft out when 60
lPlace or linkOptional
nNotesOptional
hHostOptional
zThe host's IANA time zoneOptional. The ticket shows the host's time; the preview prints the time in this zone

The format is a public contract. New keys are optional, readers ignore keys they don't know, and old links keep working.

Write one by hand

From a script, a spreadsheet or an AI assistant, write the reminder into the address. remmynd turns it into a link:

https://remmynd.space/new?t=Demo+day&at=2026-12-05T18:00&tz=Asia/Kolkata&l=https://lu.ma/demo
ParameterMeaning
tTitle (required)
atWhen, YYYY-MM-DDTHH:mm, optionally with Z or an offset like +05:30 (required)
tzIANA time zone for at, like Asia/Kolkata
dLength in minutes (default 60)
lPlace or link
nNotes
hHost

With tz, or a Z or offset in at, the address redirects to the shared link straight away. Without one, the time is read in the visitor's own time zone. If the title or time is missing, the maker opens with what was given.

Connector for AI assistants

Add remmynd to any AI assistant that takes MCP connectors (remote MCP servers), then ask it for a reminder in your own words. It answers with a link you can share or tap. No account and no key.

https://remmynd.space/mcp
ToolWhat it does
make_reminder_linkA link from a title, a start (YYYY-MM-DDTHH:mm and an IANA time zone, or an exact time), and optionally a length, a place or link, notes and a host
make_reminder_from_textA link from one line, read the way the app reads what you type: "Demo day Fri 5pm zoom.us/j/123"
read_reminder_linkWhat a remmynd link holds: title, time, length, place, notes and host

It speaks MCP 2026-07-28 (stateless, per-request versions) and the earlier versions back to 2025-03-26, over Streamable HTTP. The tools only turn words into a link and a link back into words, with the same library as this site, so the links are identical. Nothing is stored or logged, and the connector asks no other host for anything.

In your code

The remmynd package makes and reads links. Zero dependencies. Works in Node 20 and later, Deno, Bun, Cloudflare Workers and browsers. Types included.

npm install remmynd
import { createLink, toICS, googleCalendarUrl, decode, fromQuery, parse } from "remmynd";

const event = {
  title: "Demo day",
  start: "2026-12-05 18:00",
  timeZone: "Asia/Kolkata",
  location: "https://lu.ma/demo",
  durationMinutes: 90
};

createLink(event);                     // https://remmynd.space/r/eyJ0Ijoi...  shared: chat apps preview it
createLink(event, { private: true });  // https://remmynd.space/#eyJ0Ijoi...   private: never reaches a server
toICS(event);                          // .ics text with alerts 1 hour before and at the start
googleCalendarUrl(event);              // Google Calendar "add event" link
decode(link);                          // { title, start: Date, durationMinutes, location, notes, host, timeZone }
fromQuery("t=Demo+day&at=2026-12-05T18:00&tz=Asia/Kolkata");  // an event, from /new-style parameters
parse("Demo day Fri 5pm zoom.us/j/123");  // { title: "Demo day", start: Date, dur: null, place, tokens }

From the command line

npx remmynd "Demo day" --at "2026-12-05 18:00" --tz Asia/Kolkata --where https://lu.ma/demo
Options
  --at, -a       When, e.g. "2026-12-05 18:00" (local to --tz) or an ISO time with Z
  --tz, -z       IANA time zone for --at (default: your system zone)
  --where, -w    A place or a link
  --notes, -n    One line of notes
  --host         Who is hosting
  --length, -l   Minutes (default 60)
  --private, -p  Make a private link (/#…): no preview, never reaches a server
  --ics [file]   Also write an .ics file ("-" prints it)
  --badge <fmt>  Print a Remind me badge snippet: html or md
  --dark         Use the dark badge
  --google       Also print a Google Calendar link
  --json         Print everything as JSON
  --base <url>   Use your own remmynd host

remmynd read <link>   Show what is inside a remmynd link (shared or private)

Badges

Put a Remind me button anywhere a picture and a link can go. badgeHTML(link) and badgeMarkdown(link) in the library, or --badge html on the command line, write these for you.

Self-host

remmynd runs on Cloudflare Workers: the files in public/ are static assets, and worker/index.js handles shared links and their previews, /new, /ics, /changelog, /stats and phone alerts.

git clone https://github.com/Remmynd/remmynd.git
cd remmynd
npx wrangler login
npm run ship      # runs the tests, then deploys

Change name and the routes in wrangler.toml to your own first. To turn on phone alerts, run npm run push:setup once: it creates the database, makes a key pair and fills in wrangler.toml. Any static host works for the site alone, with private links.
