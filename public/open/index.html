How each number stays true

NumberHow it's checked
Stars and downloadsFetched live through /stats, cached for an hour. A tile stays hidden if its number can't be fetched.
TestsCounted from the test file. A test fails if this page and For hosts don't say the same count.
SizeThe size budget test measures every file a first visit loads, compressed, and stops a deploy that goes over.
DependenciesThe npm package has none, and package.json lists none.
Other hosts and trackersA test reads every page and script for addresses on other hosts, a strict security policy blocks them in the browser, and a scheduled check reads the live site for anything Cloudflare adds.

All of it runs in public: the checks on GitHub, and the tests themselves.

What the server keeps

Your reminder lives in the link and on your device. For phone alerts we keep only an anonymous ping time, deleted once it's sent. If you sign in, we keep your email address and your reminders so they sync across your devices and can be emailed to you. Private links stay on your device. Delete it all any time.

The details, including who delivers the emails, are on the privacy page. Every release is on the changelog.
